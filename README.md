# SCA Remediation Lab

[Open the standalone interactive evidence demo](https://dotrobin.dev/demos/sca.html)

Compare the recorded before/after inventories for minimist, tar, axios and semver. Switch evidence views to understand the audit summary, functional tests and the minimist security invariant.

This is a static portfolio replay of saved November 3, 2026 results, **not a live scanner or test runner**. It installs nothing, accepts no uploads and contacts no local machine or backend. Only minimist has demonstrated reachability in the synthetic lab; the other dependencies illustrate inventory detection and remediation.

The main application runs locally and is separate from this demo. This repository currently contains this introduction, not a complete runnable application checkout. Do not mistake the public preview for a production service or a current security certification.
